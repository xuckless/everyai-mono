# EveryAI

![App Logo](assets/logo.png)

**EveryAI** is a Flutter-based mobile application designed to provide users with an engaging and interactive AI-powered chat experience. Leveraging multiple AI models such as ChatGPT, LLaMA, Gemini, and Claude, the app offers versatile conversational capabilities tailored to user preferences. With secure authentication, including Google Sign-In, and a sleek, user-friendly interface, Second Times The Charm aims to revolutionize the way users interact with AI.

## Features

- **User Authentication:**
  - Sign-Up and Log-In functionalities with form validation.
  - Secure storage of user tokens using Flutter Secure Storage.
  - Google Sign-In integration for seamless authentication.

- **AI-Powered Chat:**
  - Multiple AI models available: ChatGPT, LLaMA, Gemini, and Claude.
  - Dynamic selection of AI models and their respective versions.
  - Rich text parsing for enhanced message formatting.

- **User Interface:**
  - Customizable App Bar and Navigation Drawer.
  - Responsive chat interface with message alignment based on the sender.
  - Loading indicators and error handling for improved user experience.

- **Secure API Communication:**
  - Robust API service handling HTTP requests with error management.
  - Dynamic base URL selection to accommodate different environments.
